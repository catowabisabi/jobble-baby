## Requirements

Create `app/(tabs)/bonding-journal.tsx` — a journal for tracking bonding moments between parent and baby.

### Features
1. **Baby Info Header** — reuse the profile baby info header pattern (baby name, DOB, age)
2. **Skin-to-Skin Timer** — start/stop timer for skin-to-skin sessions, displays elapsed time, saves duration to AsyncStorage
3. **Attachment Moment Journal** — list of journal entries with:
   - Photo capture via expo-image-picker
   - Moment type selector: first hold, first smile, first bath, feeding bond, lullaby sung, tummy time talk
   - Notes text input
   - Timestamp auto-captured
4. **Mood Check-In** — 1-5 mood scale for parent emotional health (1=struggling, 5=great), saved per day
5. **Bonding Milestones** — checkable list: first hug, first kiss, first story read, first bath, first solid food reaction
6. **History View** — chronological list of all entries grouped by day

### Data Model
- AsyncStorage: `@jobble/bonding_entries` — { id, type, photoUri?, notes, timestamp }
- AsyncStorage: `@jobble/skin_to_skin` — { totalSeconds, lastSessionSeconds, lastSessionDate }
- AsyncStorage: `@jobble/mood_checkins` — { date, score }
- AsyncStorage: `@jobble/bonding_milestones` — { milestoneId: boolean }
