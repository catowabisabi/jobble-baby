## Requirements

Create `app/(tabs)/colic-relief.tsx` — a tab to help parents navigate the Period of PURPLE Crying and colic.

### Features
1. **Crying Pattern Tracker** — log fussy episodes with duration, intensity (1-10), triggers
2. **5 S's Activation Guide** — step-by-step Swaddle, Side-hold, Shush, Swing, Suck techniques with visual guide
3. **Colic Comfort Arsenal** — bicycle legs, belly massage, warm compress, gripe water, probiotic drops logging
4. **Purple Crying Education** — explain the normalcy of excessive crying (peaking at 2 months), when to seek help
5. **Real-time Crying Timer** — track total crying hours per day vs baseline, show trend
6. **White Noise Library** — built-in white noise sounds (vacuum, fan, shusher) with timer
7. **Caregiver Stress Monitor** — if crying exceeds 5 hours/day, alert for caregiver break
8. **Pediatrician Connection** — quick notes for when crying seems abnormal (intussusception, hernia)
9. **Badge**: "Survived the Purple" — logged 7 consecutive days of colic management without escalation

### Data Model
- AsyncStorage: `@jobble/crying_episodes` — [{ id, date, durationMinutes, intensity, triggers }]
- AsyncStorage: `@jobble/comfort_arsenal` — [{ date, technique, duration }]
- AsyncStorage: `@jobble/purple_education` — { viewed: boolean }
- AsyncStorage: `@jobble/daily_crying_total` — { date, totalMinutes }
- AsyncStorage: `@jobble/white_noise_timer` — { soundType, durationSeconds }
