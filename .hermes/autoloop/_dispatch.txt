## Requirements

- All tabs should use `useLanguage()` from `../context/LanguageContext` (not useTranslation)
- All tabs should use `useTheme()` from `../context/ThemeContext`

- Check for missing loading states / error states
- Check for missing null/undefined checks on data

### 3. Accessibility
- Check for missing `accessibilityLabel` on touchable elements
- Check for sufficient color contrast (text vs background)
- Check for touch targets >= 44x44pt

### 4. UI Polish
- Check for hardcoded strings that should use i18n
- Check for inconsistent spacing/padding patterns
- Check for placeholder/TODO comments that should be resolved

### 5. Performance
