## Part 1: GitHub Actions CI/CD Pipeline for EAS Builds

Create these files:

FILE: .github/workflows/eas-build.yml
Trigger: push to main branch
Steps:
  - Checkout code
  - Setup Node.js 20
  - Run npm ci
  - Run npx expo install --check
  - Run npx tsc --noEmit
  - Run eas build --platform all --profile preview --non-interactive
  - Upload IPA and AAB as artifacts

Required secrets (use placeholder instructions):
  - EAS_TOKEN: from eas credentials
  - EXPO_APPLE_APP_SPECIFIC_PASSWORD: from Apple Developer account
  - EXPO_APPLE_TEAM_ID: from Apple Developer account

FILE: .github/workflows/test.yml
Trigger: pull request
Steps:
  - npm ci
  - npx tsc --noEmit

FILE: docs/EAS_SETUP.md
Content: Step-by-step guide for user to configure EAS credentials:
  Step 1: Create EAS account at https://expo.dev
  Step 2: Run eas credentials --platform ios to configure Apple credentials
  Step 3: Run eas credentials --platform android to configure Android credentials
  Step 4: Create EAS_TOKEN from https://expo.dev/settings/access-tokens
  Step 5: Add secrets to GitHub repo settings
