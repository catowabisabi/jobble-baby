Read src/app/subscription.tsx. Verify:

### Step 3: Backend check
Verify POST /api/v1/subscription/create endpoint exists and returns plan details.

### Step 4: Test the flow
1. Login as free user → go to subscription → see upsell
2. Login as premium user → go to subscription → see "已訂閱" badge
