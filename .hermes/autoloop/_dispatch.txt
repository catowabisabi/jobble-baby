### Features to Implement

1. **Procedure Log**
   - Log: procedure type (frenotomy, frenulectomy, ear tubes, hernia repair, other), date, surgeon/clinic name
   - Photo-capture of post-op instructions (via expo-image-picker or camera)
   - Storage key: @jobble/procedure_log

2. **Feeding Recovery Tracker**
   - For frenotomy/frenulectomy: track return to feeding
   - Input: latch quality (1-5), bottle acceptance (yes/no/partial), feeding duration (minutes), pain score during feeds (1-5)
   - Alert if no feeding for 12+ hours
   - Storage key: @jobble/feeding_recovery

3. **Pain and Comfort Score**
   - Simple 1-5 scale input with emoji indicators
   - Educational tip: how to read pain cues in infants
   - Storage key: @jobble/pain_comfort_score

4. **Medication Log**
   - Acetaminophen/ibuprofen dosing with weight-based calculator
   - Track: drug name, dose (mg), time given, response (helped/did not help)
   - Storage key: @jobble/medication_log

5. **Wound Monitoring Guide**
   - Photo-log surgical site with timestamp
   - Visual comparison cards: normal healing vs infection signs
   - Alert thresholds: fever above 38C, increasing redness/swelling
   - Storage key: @jobble/wound_photo

6. **Recovery Timeline**
   - Procedure-specific expected recovery curve displayed as progress bars
   - Frenotomy: Day 1-3 swelling expected, Day 4-7 feeding improves, Week 2 back to baseline
   - Track actual status per day
   - Storage key: @jobble/recovery_timeline

7. **Follow-up Alert**
   - Set reminder for follow-up appointment date
   - Pre-visit checklist: questions to ask, photos to bring
   - Storage key: @jobble/follow_up_alert

8. **Pediatrician Alert**
   - Escalation triggers: pain score above 3 for 3+ days, fever above 38C, no feeding for 24hrs
   - Display "Call doctor" prompt with phone shortcut
   - Storage key: @jobble/pediatrician_alert
