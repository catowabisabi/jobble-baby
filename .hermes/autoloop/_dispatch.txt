# Sisyphus Task — gear-check-reminder (ID #60)

## Objective
Implement Gear Check Reminder — a new tab for Jobble Baby app that helps parents remember everything before leaving home with baby.

## Keywords (use all 3)
gear-check, outing-checklist, diaper-bag

## What to build

Create `JobbleBaby/app/(tabs)/gear-check.tsx` — a fully functional gear/outing checklist tab:

**Core Features:**
- Context-aware checklist: diaper bag, spare clothes, formula, stroller weather cover, car seat adapter, baby blanket, changing pad, burp cloth, diaper cream, thermometer
- Trip-type selector: short walk (15min), errand (1hr), full day outing — different items per type
- Weather-aware add-ons: rain cover for rainy days, sun shade for sunny, extra layers for cold
- Check-off UI with each item as a tappable row (checked/unchecked state)
- Manual add custom item button
- AsyncStorage persistence: save checked state per trip date to `@jobble/gear_check_entries`
- Load previous checklist state on mount
- Reset checklist button for next outing
- Baby age context shown (for packing guidance)

**Implementation Pattern (follow existing tabs):**
- Use `useState` + `useEffect` for AsyncStorage load on mount
- AsyncStorage key: `@jobble/gear_check_entries`
- Use existing `useTheme()` from `../context/ThemeContext`
- Use existing `useLanguage()` from `../context/LanguageContext`
- Use `COLORS` from `../theme`
- Use `SafeAreaView` from `react-native-safe-area-context`
- Use same `generateId()` pattern from other tabs
- Icons: `@expo/vector-icons/MaterialIcons` (backpack, check-circle, add, etc.)
- No external API calls — all local

**Add to Tab Navigator:**
Edit `JobbleBaby/app/(tabs)/_layout.tsx`:
- Import `GearCheckScreen` from `./gear-check`
- Add Tabs.Screen for `gear-check` with title `t('tabs.gearCheck')` and icon `backpack`
- Use `MaterialCommunityIcons` name="backpack" or "bag-personal"
