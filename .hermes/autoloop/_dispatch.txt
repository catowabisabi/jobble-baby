# Task: Build Interview Streak Counter with Social Proof Badges

## Context
Jobble Baby - AI job-hunting app. Gamify interview practice to convert free users to premium via streak addiction + social comparison. This is concept #7 from brainstorm + todo #26.

## Painpoint
No retention mechanic for interview practice. Users try once but don't come back. Streaks create daily habit loop.

## Tasks

### 1. Database: Add streak tracking to users table
In backend (use existing SQLite or add to FastAPI models):
- Add to user model: `streak_current` (int, default 0), `streak_longest` (int, default 0), `streak_freeze_tokens` (int, default 3), `last_practice_date` (date nullable), `streak_updated_at` (datetime)
- Add model: `PracticeSession(id, user_id, score, duration_seconds, practice_type, created_at)`
- Add model: `StreakAchievement(id, user_id, badge_type, earned_at)`

### 2. Backend API endpoints (backend/app/routes/streak.py)
- GET /api/v1/streak/status → { current, longest, freeze_tokens, last_practice }
- POST /api/v1/streak/practice-complete → body: { score, duration_seconds, practice_type }
  - Update streak: if last_practice was yesterday → +1; if today → no change; if >1 day ago → reset to 1
  - If streak crosses 3/7/30 threshold → award StreakAchievement
  - Return: { streak_current, streak_longest, badge_earned?, freeze_tokens_remaining }
- POST /api/v1/streak/freeze → use 1 freeze token to protect streak for 1 missed day
- GET /api/v1/streak/leaderboard → top 10 anonymous users by streak (names hidden: "Job Seeker #1")

### 3. Frontend: StreakBadge component (src/components/streak-badge.tsx)
- Props: streakCount (number), size ('sm'|'md'|'lg')
- Tier colors: 1-2 (none/gray), 3-6 (bronze), 7-29 (silver), 30+ (gold)
- Fire emoji 🔥 scales with streak count (1-2: none, 3-6: small, 7-29: medium, 30+: large)
- Show current streak number prominently
- Frost emoji ❄️ for freeze tokens remaining

### 4. Frontend: Interview streak integration (src/app/interview-readiness.tsx)
- Add streak banner at top: "🔥 Day X streak" + freeze tokens remaining
- After completing a practice session, show streak update animation (+1 streak with celebration)
- If streak would break (missed day on next open), show "Use ❄️ to protect your streak?" modal
- Add "Streak Achievements" section showing earned badges

### 5. Shareable Achievement Card (src/components/streak-share-card.tsx)
- Canvas-based: generate shareable image (400x300)
- Shows: "I practiced X days in a row! 🎯 Score: Y.Y", tier badge, date
- Use react-native-view-shot or canvas to export as image
- "Share" button → share to social/media

### 6. Keywords
streak counter, practice session, badge tier, leaderboard, streak freeze, social proof, shareable achievement
