## Task: Fix Play Store Screenshot Dimensions

Google Play requires 1080×1920 (9:16 portrait). Current screenshots are 1080×2340 (approximately 9.8:16) — wrong aspect ratio.

### Files
All 60 PNG files in `JobbleBaby/assets/screenshots/play-store/`

### Approach
Use ImageMagick `convert` to crop each image to 1080×1920:
- Crop from center: `convert input.png -gravity center -crop 1080x1920+0+0 output.png`
- The 1080×2340 → 1080×1920 means cropping 420px from height
- Use `-gravity center` to crop from center vertically
- Overwrite original files (or save to temp, then replace)

### Command (batch)
```bash
cd JobbleBaby/assets/screenshots/play-store/
for f in *.png; do
  convert "$f" -gravity center -crop 1080x1920+0+0 "$f"
done
```

### Verification
After cropping, run:
```bash
python3 -c "
import struct, os
for f in os.listdir('.'):
    if f.endswith('.png'):

        h = struct.unpack('>I',data[20:24])[0]
        print(f'{f}: {w}x{h}')
"
```
All should show 1080x1920.
