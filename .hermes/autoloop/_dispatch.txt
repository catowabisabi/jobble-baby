fix: build live CV score counter with animated milestone rings

## Context
Jobble Baby - AI job-hunting app. When user re-scores their CV, we want a delightful animated reveal showing score improvement. Painpoint: CV score updates feel static and forgettable - no sense of progress momentum.

## Task

### 1. Build ScoreAnimation component (src/components/score-animation.tsx)
Create a reusable animated score counter component:
- Props: `score` (number), `previousScore?` (number), `size` ('sm'|'md'|'lg')
- Animated counter: when score prop changes, count from previousScore to new score using spring animation (react-native-reanimated)
- Circular progress ring around the score: shows progress toward next milestone tier
- Milestone thresholds: 5 (bronze), 7 (silver), 8.5 (gold)
- Delta badge: "+X.X" in green or "-X.X" in red, appears below counter
- Confetti burst: when crossing a milestone threshold (5→7 or 7→8.5), trigger confetti via existing confetti-burst.tsx

### 2. Integrate into profile.tsx
In the CV score display area of src/app/profile.tsx:
- Replace static score number with `<ScoreAnimation score={currentScore} previousScore={previousScore} size="lg" />`
- The component should handle the case where previousScore is undefined (first load, no animation)

### 3. Integrate into CV upload flow
In src/components/onboarding/Step1CVUpload.tsx (after AI returns score):
- Use `<ScoreAnimation score={newScore} size="lg" />` as the score reveal animation
- Trigger confetti if score >= 5

### 4. Animation specs
- Counter animation: 800ms spring, damping 15, stiffness 100
- Progress ring: SVG circle with stroke-dashoffset animation, 600ms ease-out
- Delta badge: fade in after counter completes, 200ms
- Confetti: 2 second burst, gravity-affected particles

### 5. Verify TypeScript
Run `npx tsc --noEmit` to ensure no type errors.
