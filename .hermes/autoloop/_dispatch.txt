Implement Concept #26: Caregiver Fatigue & Resilience Tracker.

## Requirements

Create `app/(tabs)/caregiver-fatigue.tsx` — a tab for tracking caregiver burnout and resilience.

### Features
1. **Burnout Trajectory Survey** — one-time assessment: rate current exhaustion (1-5), sleep quality (1-5), support network size (1-5), mental load (1-5), guilt level (1-5). Stored in AsyncStorage.
2. **Daily Resilience Check-In** — 1-5 scale per day: energy, mood, patience, connection. Simple tap interface.
3. **Mental Load Mapping** — list of caregiving tasks (feeding, sleep, diaper, medicine, appointments, etc.) with estimated hours. Shows total mental load hours per day.
4. **Rest Quantum Calculator** — parent inputs available rest windows (even 15 min blocks). Shows cumulative rest credit vs recommended minimum (based on baby age).
5. **Caregiver Resilience Score** — composite 0-100 score: burnout trajectory + 7-day check-in average + rest credit. Color-coded (red <40, yellow 40-70, green >70).
6. **Exhaustion Threshold Alert** — if resilience score drops below 40 for 5 consecutive days, show "Consider asking for help" banner with suggestion to use shift-handoff tab.
7. **Respite Scheduling Engine** — parent sets "respite goal" (e.g., 2 hours per week). App tracks actual vs goal. Alert if goal missed 3 weeks in a row.
8. **Shift Handoff Integration** — link to shift-handoff tab; show "delegate more" suggestion if resilience score is low.
9. **Badge**: "Resilience Champion" — 7-day streak maintaining resilience score > 80%.

### Data Model
- AsyncStorage: `@jobble/caregiver_survey` — { date, exhaustion, sleepQuality, supportNetwork, mentalLoad, guiltLevel }
- AsyncStorage: `@jobble/resilience_daily` — [{ date, energy, mood, patience, connection }]
- AsyncStorage: `@jobble/mental_load_tasks` — [{ id, label, estimatedHours }]
- AsyncStorage: `@jobble/respite_goal` — { weeklyHoursGoal, totalWeeks }
- AsyncStorage: `@jobble/resilience_score` — { currentScore, streakDays }
