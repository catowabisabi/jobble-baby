## Task
Build job alert / recruiter radar system:

### Backend (FastAPI):
1. Create PATCH /api/v1/users/alert-preferences to save user notification preferences (job_types[], salary_min, locations[], keywords[])
2. Create GET /api/v1/users/alert-preferences to retrieve saved preferences
3. Create GET /api/v1/jobs/matches?user_id=X - return matching jobs based on user preferences from real_jobs.json (reuse existing job data). Match on: job_type, salary >= salary_min, location, keywords in job title/description
4. Create POST /api/v1/notifications/send - trigger push notification (store in DB for now, Expo Push later)
5. Add last_alert_sent_at to user preferences tracking

### Frontend (React Native/Expo):
1. Create src/app/job-alerts.tsx - settings screen where user configures:
   - Job types (multi-select chips): Backend, Frontend, Full Stack, DevOps, Data, Mobile, PM, Design
   - Minimum salary (numeric input with HKD prefix)
   - Locations (multi-select): Hong Kong, Remote, Kowloon, New Territories
   - Keywords (text input, comma-separated)
   - Notification toggle (enable/disable alerts)
   - Save button → PATCH alert-preferences

2. Update src/app/profile.tsx - add "Job Alerts" button navigating to /job-alerts, show match count badge if preferences saved

3. Add src/components/job-match-card.tsx - display matched job with company, title, salary, match score percentage

4. Add alert badge on tab bar (Bell icon) when alerts configured

### Data Flow:
User sets preferences → stored in DB → matches computed against real_jobs.json → displayed on profile as "X jobs match you" → Expo Push notification when new matching job appears
