fix: build onboarding wizard with 4-step activation flow

## Context
Jobble Baby is an AI job-hunting assistant app. User uploads CV → gets AI help → subscribes. Concept #5 is an Onboarding Wizard that accelerates the Aha Moment from 3-5 days to under 5 minutes.

## Concept
4-step first-launch wizard:
1. Upload CV → instant AI score reveal (Aha Moment)
2. Set job preferences → immediate job matches
3. Try one interview question → instant AI feedback
4. Enable notifications → recruiter radar activates

Progress bar + badges per step. Skip available but discouraged.

## Task

### Step 1: Create onboarding screen
Create src/app/onboarding.tsx - full-screen 4-step wizard:
- Step indicator (1/4, 2/4, 3/4, 4/4) with animated progress line
- Button-based navigation (Next/Back)
- Each step has clear CTA + small reward

### Step 2: Step content
- Step 1 (Upload CV): File picker for CV → POST /api/v1/cv/upload → score reveal animation (1-10 with category breakdown). Aha Moment - make it magical.
- Step 2 (Job Preferences): Form - job type (dropdown), location (dropdown), salary expectation (slider). Show "Found X matching jobs" with preview cards.
- Step 3 (Try Interview): One HR question, text input, POST /api/v1/interviews/submit → show AI feedback.
- Step 4 (Notifications): Push notification toggle. Request permission. Radar activation animation. "Your recruiter radar is now active."

### Step 3: Gate first-launch users
In src/app/_layout.tsx, check onboarding_complete in SecureStore. If missing, redirect to /onboarding. After step 4 completion, set onboarding_complete=true and redirect to home.

### Step 4: Backend endpoint
POST /api/v1/onboarding/complete - Body: { step: 1|2|3|4, preferences?: {...} }. Track completion in user metadata. Update user profile with job_preferences from step 2.

### Step 5: Style
Use existing theme. Progress bar at top with animated fill. Large touch targets. Celebration micro-animation on step completion.
