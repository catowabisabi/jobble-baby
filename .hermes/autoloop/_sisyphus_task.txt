# Sisyphus Task — Cycle 254

## Context
Jobble Baby: 57 tabs, TSC 0 errors, 101 todos complete. Cycle 254 — Accessibility audit and improvement task. The app targets parents of infants and should be WCAG 2.1 AA compliant. Project is in pre-launch state.

## Task: Accessibility Audit & Improvement

Improve accessibility across all 57 tabs for WCAG 2.1 AA compliance. Focus areas:

### 1. Color Contrast
Review all text/background color combinations. Ensure:
- Normal text (under 18pt): contrast ratio >= 4.5:1
- Large text (18pt+ or 14pt bold): contrast ratio >= 3:1
- Update COLORS in `app/theme.ts` or inline styles where needed
- Do NOT change the dark mode color scheme — only improve insufficient contrast in light mode

### 2. Accessibility Labels
Add missing `accessibilityLabel` and `accessibilityHint` to:
- All TouchableOpacity/TouchableWithoutFeedback components
- All custom buttons and interactive elements
- Format: `accessibilityLabel="[clear action]"` and `accessibilityHint="[what happens when tapped]"`

### 3. Touch Targets
Ensure all interactive elements:
- Minimum size of 44x44 points
- Adequate spacing between adjacent targets (at least 8pt)

### 4. Accessibility Roles
Add proper `accessibilityRole`:
- `button` for buttons, `link` for links
- `header` for section headers
- `image` for informative images (with accessibilityLabel)
- `search` for search inputs, `switch` for toggles

### 5. Focus Management
Ensure navigable via VoiceOver/TalkBack:
- All meaningful content has accessibility labels
- Images that convey information have descriptive labels
- Decorative images marked with `accessibilityElementsHidden={true}`

### Implementation Notes
- Work tab by tab — pick 5-6 tabs per batch
- Run `npx tsc --noEmit` after each batch — 0 errors required
- Do NOT change business logic or functionality
- Do NOT commit — just update the files
- Focus on most used tabs first: Home, Tracking, Schedule, Growth, Products, Milestones
