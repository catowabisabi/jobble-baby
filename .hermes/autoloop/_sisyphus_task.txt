## Concept (from DB concept #8)
Habit Reset Protocol: post-regression parent self-recovery tracker. After baby sleep regression or illness disrupts parent routines, this tab helps rebuild sleep schedule, exercise, nutrition, and self-care habits with gentle daily nudges and progress visualization. Prevents parental burnout spiral. Synergizes with sleep debt dashboard and shift handoff. AsyncStorage: @jobble/habit_reset_entries.

## Requirements

### 1. Create habit-reset.tsx tab
Implement a parent self-recovery tracker with these sections:

**A. Daily Check-In Card**
- 4 habit categories: Sleep, Exercise, Nutrition, Self-Care
- Each category: binary checkbox + optional note
- Daily streak counter per category
- Visual streak flame icon when streak >= 3

**B. Weekly Reset Score**
- Composite 0-100 score from % completion across categories
- Line chart showing score over past 7 days
- Color coded: red (<40), yellow (40-70), green (>70)

**C. Gentle Nudge System**
- Time-of-day based prompts: morning (exercise), afternoon (nutrition), evening (self-care), night (sleep)
- Soft notification cards with encouraging copy
- Dismissible with "Done" tap

**D. Regression Context Logger**
- Brief log entry: what disrupted the routine (baby illness, travel, regression, work stress)
- Date picker for when disruption started
- Optional: link to baby health events from other tabs

**E. Recovery Timeline**
- Visual timeline from disruption date to current
- Milestone markers: "First good night sleep", "Exercise goal met", "Back on track"
- Projected "full recovery" date based on streak data

**F. Integration Badges**
- Synergy with sleep-debt tab: show cumulative sleep debt
- Synergy with shift-handoff tab: show shift partner status
- Badge notification if partner also using habit reset
