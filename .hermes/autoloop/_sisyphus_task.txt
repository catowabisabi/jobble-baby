## Task: Implement Accessibility Audit & Improvement (Todo #101)

### Objective
Audit and improve accessibility across the app — focus on contrast, labels, and touch targets per WCAG 2.1 AA standards.

### Instructions

1. **Scan existing tabs** for accessibility issues — pick 5-6 tabs per batch
   - Most-used tabs first: Home (index.tsx), Tracking, Schedule, Growth, Products, Milestones

2. **For each tab, fix:**
   - **Contrast**: Text/background color contrast ratio ≥ 4.5:1 for normal text, ≥ 3:1 for large text
   - **Touch targets**: Minimum 44x44px for all interactive elements (TouchableOpacity, Pressable, Button)
   - **Accessibility labels**: All meaningful content has proper labels; decorative elements have `accessibilityElementsHidden={true}`
   - **Image labels**: Any Image that conveys information needs `accessibilityLabel`

3. **Files to check (first batch — 6 tabs):**
   - `app/(tabs)/index.tsx` (Home)
   - `app/(tabs)/tracking.tsx`
   - `app/(tabs)/schedule.tsx`
   - `app/(tabs)/growth.tsx`
   - `app/(tabs)/products.tsx`
   - `app/(tabs)/milestones.tsx`

4. **Fix approach:**
   - Do NOT change business logic or functionality
   - Only update styles for contrast/touch targets
   - Add accessibility labels where missing
   - Use `accessibilityHint` for complex interactions
   - Do NOT commit — just update the files

5. **After each batch:**
   - Run `npx tsc --noEmit` — 0 errors required
   - Run `npx expo export --platform ios` (or check with Expo) to verify no build errors
