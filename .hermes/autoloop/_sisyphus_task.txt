# Sisyphus Task — Cycle 275

## Context
Jobble Baby: TSC 0 errors, 66 tabs. All major features implemented. App ready for App Store submission pending user actions.

## Task: Codebase Polish & Cleanup

Perform a final polish pass across the entire tab codebase.

## Requirements

### 1. Remove Debug Code
Search all tab files in `JobbleBaby/app/(tabs)/` for:
- `console.log(` — remove or replace with `// debug: ...` commented block
- `console.warn(` — remove or comment out
- `console.error(` — keep only for genuine errors, comment out for debugging
- `TODO` comments that are not actionable — convert to `// FIXME: [describe issue]` or remove
- `FIXME` without a description — add description or remove

### 2. Check AsyncStorage Keys
Verify all tabs use consistent AsyncStorage key prefix `@jobble/`. Report any tabs using non-prefixed keys or inconsistent naming.

### 3. i18n Audit
Check that NO tab has hardcoded Chinese or English strings that should be in i18n. Search for:
- Chinese characters (一乙二十丁厂七卜八人入八九刁十刀又三于干上下不) in TSX files — these should be in zh.json
- Plain English strings that should be i18n keys (button text, labels, placeholders)

### 4. Accessibility Spot Check
Run accessibility audit on 5 random tabs. For each:
- Check that all Touchable components have accessibilityLabel
- Check that all images have accessibilityRole="image" and alt text

### 5. Theme Consistency
Verify all tabs import COLORS from `../theme` and use theme context (`useTheme()`) instead of hardcoded color values.

### Output
- List of changes made (file, change type, description)
- Report of any issues found but not fixed (with file paths and line numbers)
- TSC must remain 0 errors after changes
