## Task: Implement Solid Food Progression Navigator Tab

Create a tab for tracking a baby's solid food journey from first tastes (6mo) to family meals (12mo+).

## Requirements

### Tab Name
`solid-food` — add to `JobbleBaby/app/(tabs)/` and register in `_layout.tsx`

### Features
1. **Stage Tracker**
   - Stage 1 (6-7mo): Single ingredient purees, 4-6 days per food
   - Stage 2 (7-9mo): Combined flavors, thicker textures
   - Stage 3 (9-12mo): Finger foods, self-feeding practice
   - Stage 4 (12mo+): Family food adaptation
   - Visual stage indicator with months range

2. **Food Introduction Journal**
   - Log each food: name, date introduced, amount, reaction (none/mild/moderate/severe)
   - Timeline view of all introductions sorted by date
   - Filter by allergen/non-allergen

3. **Allergen Introduction Tracker**
   - Track 8 priority allergens: peanut, egg, milk, soy, wheat, tree nuts, fish, shellfish
   - Status per allergen: not_yet/introduced/reacted
   - Reaction log with date, food, severity

4. **Texture Progression Guide**
   - Level 1: Smooth puree (6mo)
   - Level 2: Mashed/ground (7mo)
   - Level 3: Chopped soft (9mo)
   - Level 4: Family texture (12mo)
   - Red flag alerts if texture is behind schedule

5. **Iron & Nutrient Tracking**
   - Track iron-rich foods (fortified cereal, meat, beans, leafy greens)
   - Daily nutrient summary
   - Gap alerts for key nutrients

6. **Correlation Links**
   - Link to allergens tab (shared allergen log)
   - Link to growth tab (weight impact of solids)
   - Link to gut-brain-axis tab (digestive reactions)
   - Link to teething tab (teething → food refusal)

7. **i18n**
   - Add keys under `solidFood.*` in en.json + zh.json
   - All user-facing strings must use i18n
