## Requirements

### Core Features
1. **Sensory Domain Dashboard**: 7 domains tracked with radar/spider chart visualization:
   - Tactile (touch texture discrimination, pressure response, temperature sensitivity) — orange
   - Vestibular (movement detection, balance, spatial orientation) — purple
   - Proprioceptive (body awareness, weight-bearing, motor planning) — blue
   - Visual (tracking, focus, visual-motor integration) — green
   - Auditory (sound localization, discrimination, auditory-motor linking) — yellow
   - Oral-Motor (suck-swallow-breathe, oral awareness, food texture tolerance) — pink
   - Interoceptive (hunger/fullness, thirst, need for elimination, pain) — teal
2. **Age-Based Milestone Bands**: Each domain has 0-12 month milestones with color-coded timeline bands
3. **Baby Current Position**: Calculate from baby's birth date — show which sensory windows are ACTIVE, IMMINENT (within 2 weeks), or PASSED
4. **Sensory Quick Log**: One-tap log entry per domain — observation text + intensity 1-5 + optional notes
5. **Domain Score Calculation**: 0-100 score per domain computed from logged entries + baby age
6. **Cross-Modal Correlation View**: Show correlations between domains (e.g., tactile play → vestibular improvement)
7. **Red Flag Alerts**: Alert if domain scores plateau or regress >2 months
8. **Sensory Diet Suggestions**: Context-aware activities based on active sensory windows
9. **Progress Dashboard**: Show coverage of all 7 sensory domains

- @jobble/sensory_domain_scores: JSON { [domain_id]: score_0_100 }
