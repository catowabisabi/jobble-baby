# Task: Build Subscription Paywall with Feature Gating

## Context
Jobble Baby - AI job-hunting app. Painpoint #10: No premium upsell/subscription UI. Users need to see what they're missing and want to upgrade.

## Your Tasks

### Audit subscription.tsx
Read src/app/subscription.tsx. Verify it has:
- Free tier with locked features (padlock icon)
- Pro (HK$99/mo) and Premium (HK$199/mo) tier comparison
- "立即訂閱" CTA buttons
- Premium badge for subscribed users

### Feature Gating
Check these screens for premium gating:
- src/app/interview.tsx - AI interview should be premium-only
- src/app/cv-detail.tsx - CV optimization should be premium-only  
- src/app/job-alerts.tsx - Push notifications should be premium-only

For each locked feature:
- Show content blurred or with padlock overlay
- Show floating upsell banner: "升級至 Premium 解鎖全部功能 HK$199/月"

### Verify Backend
Check backend has POST /api/v1/subscription/create endpoint.
