# Task: Build Interview Streak Counter with Social Proof Badges

## Context
Jobble Baby - AI job-hunting app. Gamify interview practice to convert free users to premium via streak addiction + social comparison. Concept #7 + todo #26.

## Painpoint
No retention mechanic for interview practice. Users try once but don't come back. Streaks create daily habit loop.

## Tasks

### 1. Database models (backend/)
- Add to user model: streak_current, streak_longest, streak_freeze_tokens (default 3), last_practice_date, streak_updated_at
- PracticeSession: id, user_id, score, duration_seconds, practice_type, created_at
- StreakAchievement: id, user_id, badge_type (bronze_3day/silver_7day/gold_30day), earned_at

### 2. Backend API (backend/app/routes/streak.py)
- GET /api/v1/streak/status → { current, longest, freeze_tokens, last_practice }
- POST /api/v1/streak/practice-complete → update streak logic, award badge if crossed threshold
- POST /api/v1/streak/freeze → use 1 freeze token
- GET /api/v1/streak/leaderboard → top 10 anonymous ("Job Seeker #1")

### 3. StreakBadge component (src/components/streak-badge.tsx)
- Props: streakCount, size (sm/md/lg)
- Tier colors: <3 gray, 3-6 bronze 🔥, 7-29 silver 🔥🔥, 30+ gold 🔥🔥🔥
- ❄️ for freeze tokens

### 4. interview-readiness.tsx integration
- Streak banner at top
- After practice complete → streak animation
- Streak break protection modal

### 5. Shareable achievement card (src/components/streak-share-card.tsx)
- Canvas export image (400x300)
- "I practiced X days in a row! 🎯 Score: Y.Y"
- Share button
