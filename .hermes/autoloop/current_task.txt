## Task: Implement Growth Velocity Tracker

Enhance the existing `app/(tabs)/growth.tsx` with a new "Growth Velocity Tracker" section. This is an ADDITIVE enhancement — do NOT remove existing functionality.

### Features to Add

1. **Growth Velocity Visualization**
   - Calculate and display velocity of growth (cm/month) over time
   - Show acceleration/deceleration phases against WHO velocity standards
   - Line chart showing growth velocity with WHO velocity zones (low/normal/high)
   - Storage key: `@jobble/growth_velocity_data`

2. **Velocity Alert System**
   - Alert when growth velocity drops below expected range
   - Configurable thresholds (mild/moderate/severe)
   - In-app notification when velocity concern detected
   - Storage key: `@jobble/velocity_alert_threshold`

3. **Skinfold Tracking**
   - Record skinfold measurements (triceps, subscapular) for nutritional status
   - Track skinfold ratio over time
   - Visual indicator of fat stores
   - Storage key: `@jobble/skinfold_entries`

4. **Ponderal Index Calculator**
   - Ponderal Index = weight(kg) / height(m)³
   - For low birth weight detection and monitoring
   - Display against WHO Ponderal Index standards
   - Storage key: `@jobble/ponderal_index`

5. **Mid-Parental Height Target Line**
   - Calculate mid-parental height (MPH) target
   - Boys: (father height + mother height + 13) / 2
   - Girls: (father height + mother height - 13) / 2
   - Display target range on growth chart
   - Storage key: `@jobble/parental_heights`

6. **Growth Phase Indicators**
   - Identify and label growth phases (infancy, toddler, preschool)
   - Show current phase on chart
   - Highlight transition periods
