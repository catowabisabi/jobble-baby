## Full Implementation Details

### State
- entries array: { id, date, food_name, window (1-6), rash_type (none/mild/moderate/severe), rash_location[], gi_symptoms[], stool_type, notes, badge_earned }
- windowLabels: ["Days 1-2", "Days 3-4", "Days 5-7", "Week 2", "Week 3", "Week 4"]
- selectedFood string, selectedWindow number (1-6), isAddingEntry boolean

### UI Components
1. Header: "Weaning Rash Six-Track" (en) / "加固疹追蹤" (zh)
2. Greeting: "Track your baby's reaction to new foods"
3. 6-Window Timeline: horizontal segmented progress with window labels
4. Food Entry Form (modal):
   - Food name input (text)
   - Window selector (1-6 as segmented control)
   - Rash Type: 4-button selector (None/Mild/Moderate/Severe) with color coding
   - Rash Location: multi-select chips (face, torso, arms, legs, diaper area, other)
   - GI Symptoms: multi-select chips (vomiting, diarrhea, constipation, bloating, blood in stool, gassy)
   - Stool Type: 5-button selector (normal/soft/runny/hard/mucousy)
   - Notes: multiline text input
   - Save button
5. FPIES Alert Banner: red banner if rash occurs within 72h of new food
6. History: FlatList of past entries grouped by window
7. Milestone badge: "Food Explorer" when 3+ different foods logged

### AsyncStorage
- @jobble/weaning_rash_entries
- @jobble/weaning_foods_list (for autocomplete)
- calcWindow returns 1-6 based on days since food introduction
