## Technical Notes

### Runtime Limitations
React Native apps run at RUNTIME on device/simulator, which means:
1. Cannot scan source files (.tsx) at runtime - they are bundled into the app
2. Cannot check filesystem for build artifacts (android/app/build, ios/)
3. Hardcoded string detection requires pre-build analysis via Node.js script

### Workarounds Implemented
- i18n check: Uses KNOWN_T_KEYS list (snapshot of known t() keys) to validate against i18n files
- Hardcoded check: Returns SKIP with message directing to build-time script
- Build artifacts: Returns SKIP with guidance to run locally before submission
