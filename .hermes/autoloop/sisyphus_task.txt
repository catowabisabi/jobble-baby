# Sleep Association Pattern Map — Task for Sisyphus

## Goal
Implement **Sleep Association Pattern Map tab** — log and track what sleep associations baby uses to fall asleep (pacifier, swaddle, white noise, rocking, feeding, blackout, etc.), correlate associations with night waking frequency and sleep quality, identify dependency risks, and suggest gradual fade-out schedules.

## Reference
Use existing tabs as patterns: sleep-training.tsx (check-ins/night logging), milestones.tsx (badges), tracking.tsx (entry cards).

## State
entries array: { id, date, associations: string[], fallingAsleepMinutes, nightWakings, longestStretch, qualityRating, notes, alert_triggered }
AsyncStorage: @jobble/sleep_association_entries

## Associations List (multi-select)
- pacifier, swaddle, white_noise, rocking, feeding_to_sleep, blackout_curtain, room_dark, fan, music, massage, cuddling, teether, comforter, other

## UI Components
1. Header: "Sleep Association Map" (en) / "睡眠關聯圖" (zh)
2. Alert Banner: orange if baby relies on feeding_to_sleep association for >60% of entries (sleep dependency risk)
3. Tonight's Log Card: multi-select association chips, falling-asleep time input (minutes), quality slider (1-5 stars)
4. Association Frequency Chart: bar chart showing % usage per association over last 14 days
5. Waking Correlation: simple scatter or grouped bar — which associations correlate with fewer night wakings
6. Fade-Out Tracker: if feeding_to_sleep used >60%, show gradual fade-out plan (replace with rock → replace with cuddle → replace with patting)
7. History: FlatList of past entries grouped by date
8. Milestone badge: "Sleep Architect" when 7+ entries logged
