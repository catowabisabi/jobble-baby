## Data Model
```typescript
// @jobble/cry_entries — Array<CryEntry>
interface CryEntry {
  id: string;            // uuid
  timestamp: string;    // ISO8601
  duration_minutes: number;
  cause_tag: 'hunger' | 'overtired' | 'teething' | 'reflux' | '分离焦虑' | 'other';
  intensity: 1 | 2 | 3 | 4 | 5;  // 1=mild whimper, 5=screaming
  notes?: string;
}
```

## UI Layout
1. **Header**: "Cry Frequency Analyzer" (en) / "哭聲分析器" (zh)
2. **Big + Button** (center bottom, large 64px tap target): "Log Cry" — opens entry modal
3. **Cry Entry Modal** (when + tapped):
   - Duration: minutes picker (1-120)
   - Cause: chip selector (hunger / overtired / teething / reflux / separation anxiety / other)
   - Intensity: 1-5 slider with labels (1=Whimper, 3=Medium, 5=Screaming)
   - Notes: optional text
   - Save button
4. **Today's Summary Card** (top):
   - Total cry episodes today
   - Total cry minutes today
   - Color-coded severity bar: green (<30min), yellow (30-90min), red (>90min)
5. **Weekly Cry Score Chart**: Bar chart — cry minutes per day for last 7 days
   - Baseline line: age-expected colic threshold (6wk peak = 180min/day)
6. **Cry Pattern Timeline**: Vertical timeline of today's cry episodes overlaid with sleep/feeding entries from @jobble/tracking_entries
7. **Colic Alert Banner**: Red banner if current week avg > colic threshold for baby's age
   - Colic curve: 6 weeks peak, resolves by 12-16 weeks
8. **History**: FlatList of past 30 days entries, grouped by date
