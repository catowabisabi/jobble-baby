### 2. Home Dashboard Widget

### 3. Projection Logic (all local, no server)
- **Sleep regressions**: Wolke/Paul model peaks at 4mo, 8mo, 12mo (±2 weeks). Calculate from baby's birth date stored in @jobble/baby_profile. Show countdown to next regression if within 12 weeks.
- **Growth projection**: Read @jobble/growth_entries, calculate velocity (g/day or cm/day), project forward using WHO percentile bands. Show trajectory line.
- **Feeding evolution**: Based on baby age, project milk-to-solid transition timing (around 6 months). From feeding frequency data in @jobble/tracking_entries.
- **Wake window progression**: Age-based optimal wake windows, show current + next window coming.
- **Teething forecast**: From @jobble/teething_entries and baby's age, project which teeth are expected in next 6 months.

### 4. Data Reading (read-only)
- @jobble/baby_profile: { birthDate, name, gender }
- @jobble/growth_entries: [{ date, weight, height, headCirc }]
- @jobble/teething_entries: [{ toothId, eruptionDate, painLevel }]
- @jobble/tracking_entries: [{ date, type, ... }]
- @jobble/sleep_training_entries: [{ date, nightSleep, naps, disruptions }]
- @jobble/milestone_entries: [{ id, date, type }]

### 5. Confidence Scoring
- High (>80%): 4+ data points for the metric, consistent pattern
- Medium (50-80%): 2-3 data points
- Low (<50%): 1 data point or extrapolation only
