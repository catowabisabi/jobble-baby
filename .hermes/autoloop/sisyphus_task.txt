## Task: Implement Stranger Danger Navigator — 8-Month Separation Anxiety Tracker

Create a new tab for tracking and managing stranger wariness and separation anxiety at 8-10 months.

## Requirements

### Tab Name
`stranger-danger` — add to `JobbleBaby/app/(tabs)/` and register in `_layout.tsx`

### Features
1. **Stranger Wariness Dashboard**
   - Display baby's current stranger wariness phase (none → emerging → peak → resolving)
   - Age-based phase prediction using AAP developmental windows
   - Educational explanation: "Stranger wariness is a cognitive milestone — baby recognizes familiar vs unfamiliar"

2. **Familiar Face Registry**
   - Log people baby knows: parents, grandparents, siblings, caregivers, daycare staff
   - Track exposure level: daily caregiver, weekly visitor, occasional acquaintance
   - Photo reference for caregiver identification (optional)
   - Show which people baby has met and reaction logged

3. **Gradual Introduction Protocol**
   - Step-by-step protocol: familiar face → familiar in new place → new face in familiar place → new face in new place
   - Progress tracker per person being introduced
   - Tips per stage: "Let baby observe from arms length", "Let baby reach out first", "Don't force interaction"

4. **Separation Anxiety Toolkit**
   - Departure ritual builder: 3-step consistent goodbye routine
   - Separation practice game: peekaboo variants for building object permanence
   - Signal object: familiar item baby can hold during separations
   - Reunion celebration: special greeting when parent returns

5. **Departure Tracker**
   - Log separations: duration, caregiver, baby's reaction (1-5 distress scale), parent's anxiety level
   - Track trend: are separations getting easier over time?
   - Correlation: separation difficulty vs developmental storm phase

6. **Storm Integration Card**
   - If 8-month storm tab exists, show current storm severity score
   - Link separation anxiety to other storm factors (motor, sleep, circadian)
