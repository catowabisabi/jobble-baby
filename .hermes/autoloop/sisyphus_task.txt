## Your Task
Implement a new tab: `app/(tabs)/tongue-tie.tsx`

### Features Required

1. **Hazelbaker Assessment Score**
   - 6 functional items: tongue lift, tongue extension, tongue spread, tongue snap-back, tongue hollowing, tongue peristalsis
   - Each scored 0-2 (absent/partial/complete)
   - Total score 0-12: 0-5 = significant tie, 6-8 = moderate, 9-12 = functional
   - Visual guide showing 4 tongue tie types (anterior, posterior, submucosal, lingual frenulum)
   - Photo comparison cards: normal vs tethered frenulum

2. **Jaw Symmetry Checklist**
   - 5 visual indicators: chin deviation at rest, chin deviation on cry, lip asymmetry, bite alignment, masseter muscle tone
   - Each: Yes/No + optional photo
   - Notes field for parent observations

3. **Feeding Efficiency Log**
   - Log per feeding: latch quality (1-5), duration (minutes), milk transferred (ml if weighed), bottle flow rate (slow/medium/fast/nipple_size), gag episodes count
   - Display: today's log + 7-day trend chart (bar chart, avg latch quality)
   - Correlation: feeding efficiency vs weight gain (links to growth.tsx data)

4. **Correlation Dashboard**
   - Overlay: latch quality trend + weight gain velocity + cry frequency (from cry-analyzer if available)
   - Alert threshold: "Feeding difficulty detected — consider tongue tie assessment" shown when latch quality <3 for 5+ consecutive entries

5. **Chewing Milestone Tracker**
   - Timeline stages: suck (0-3mo) → suck-swallow-breathe (3-6mo) → chewing (6-9mo) → biting (9-12mo)
   - Log: date, milestone type, food item introduced, gag episodes, refusal events
   - Visual timeline display

6. **Referral Export**
   - Button: "Share with Pediatrician"
   - Generates: assessment score + feeding log summary + growth chart snippet
   - Uses expo-print or expo-sharing to export as PDF
