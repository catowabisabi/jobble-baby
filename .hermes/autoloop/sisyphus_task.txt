# Task: Implement Post-Procedure Feeding & Recovery Navigator (concept #49, todo #122)

## Overview
Create a new tab `procedure-recovery.tsx` in `app/(tabs)/` that helps parents track infant recovery after minor procedures (frenotomy, frenulectomy, ear tubes, hernia repair).

## UX Flow
1. **Procedure Log**: procedure type picker, date, surgeon/clinic name, photo-capture of discharge instructions
2. **Feeding Recovery Tracker**: latch quality (1-5), bottle acceptance, feeding duration, pain response during feeds. Alert if no feeding for 12+ hours
3. **Pain & Comfort Score**: 1-5 scale, correlates with feeding willingness
4. **Medication Log**: drug picker (acetaminophen/ibuprofen), dose calculator (mg/kg), timing log, response tracking
5. **Wound Monitoring Guide**: photo-log surgical site, healing status picker (normal/suspicious), date
6. **Recovery Timeline**: procedure-type-specific expected curve (Day 1-3 swelling, Day 4-7 feeding improves, Week 2 baseline), track actual vs expected milestones
7. **Follow-up Alert**: set reminder, pre-visit checklist
8. **Doctor Alert**: if pain >3 for 3+ days OR fever >38C OR no feeding for 24hrs → prompt to call pediatrician

## Data Model (use @jobble/ namespaced AsyncStorage keys)
- `@jobble/procedure_log`: {date, procedure_type, clinic, surgeon, photo_uri}
- `@jobble/feeding_recovery`: [{date, latch_quality, duration_min, pain_score, notes}]
- `@jobble/medication_log`: [{date, drug, dose_mg, weight_kg, response}]
- `@jobble/wound_photo`: [{date, procedure_type, photo_uri, healing_status}]
- `@jobble/recovery_timeline`: {procedure_type, milestones: [{day, expected, actual}]}
