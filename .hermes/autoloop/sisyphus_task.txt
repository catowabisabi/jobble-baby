## Task: Implement Jaundice Threshold Chart tab

Create a new tab for tracking bilirubin levels with risk zone visualization.

## Requirements

### Tab Name
`jaundice-threshold` — add to `app/(tabs)/` and register in `_layout.tsx`

### Features
1. **Bilirubin Level Input**
   - Input field for total serum bilirubin (TSB) in mg/dL or μmol/L
   - Unit toggle: mg/dL ↔ μmol/L (1 mg/dL = 17.1 μmol/L)
   - Date/time stamp for each entry

2. **Risk Zone Chart**
   - Plot bilirubin level on an age-based threshold chart
   - Show 3 zones: Low Risk (green), Monitor (yellow), Treat/Exchange (red)
   - X-axis: baby's age in hours (0-336h / 14 days)
   - Y-axis: bilirubin level
   - Use a simple SVG line chart (no external chart library needed)
   - Overlay threshold curves for different risk categories (low, medium, high)

3. **Threshold Reference**
   - Display Bhutani nomogram-based thresholds
   - Show zone labels and what action to take per zone
   - Disclaimer: "Consult your pediatrician for medical decisions"

4. **History Log**
   - Simple list of past readings with timestamp and zone
   - Show trend arrow (↑ rising, ↓ falling, → stable)

### Technical
- Use React Native `Svg` for the chart (from `react-native-svg`)
- TSC 0 errors
- Follow existing tab pattern (Expo Router file-based routing)
- i18n keys in en.json + zh.json (add new keys)
- Accessibility: proper labels, sufficient contrast
