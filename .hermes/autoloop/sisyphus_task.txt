# Medicine Dose Calculator — Task for Sisyphus

## Goal
Implement **Medicine Dose Calculator tab** — calculate correct medication dosage based on baby's weight and age, provide weight-based dosing charts for common baby medications (acetaminophen, ibuprofen, diphenhydramine), dosage alerts for max daily limits, and conversion helpers (ml ↔ tsp ↔ drops).

## State
- baby weight from @jobble_baby_profile
- selected medication (acetaminophen/ibuprofen/diphenhydramine/other)
- weight input override option
- calculated dose result
- dosage history log

## Medications Data
### Acetaminophen (Tylenol/Paracetamol)
- 10-15 mg/kg per dose
- Max 75 mg/kg/day
- Dosing interval: every 4-6 hours
- Concentration: 160mg/5ml (infant drops)

### Ibuprofen (Advil/Motrin)
- 5-10 mg/kg per dose
- Max 40 mg/kg/day
- Dosing interval: every 6-8 hours
- Concentration: 100mg/5ml

### Diphenhydramine (Benadryl)
- 0.5-1 mg/kg per dose
- Max 5 mg/kg/day (divided)
- For allergic reactions only
- Age limit: not for infants <6 months

## UI Components
1. Baby Profile Card: auto-loaded weight, age from profile
2. Medication Selector: dropdown of common medications
3. Weight Input: editable weight override (kg + lbs toggle)
4. Dose Calculator: shows calculated dose in ml
5. Conversion Panel: ml ↔ tsp ↔ drops (1 tsp = 5ml, 1ml = 20 drops)
6. Max Daily Alert: red banner if dose exceeds max
7. Dosing Schedule: frequency reminder (q4h, q6h, q8h)
8. History Log: FlatList of recent dose calculations
9. Milestone badge: "Dose Guardian" when 5+ calculations logged
