# Sisyphus Task — Cycle 239

## Context
Jobble Baby: TSC 0 errors, 50+ tabs, accessibility fixed. App is feature-complete. Remaining blockers are user-action items. This task creates an interactive checklist tab to guide through all pre-submission requirements.

## Task: Implement App Store Launch Interactive Checklist tab

Create `app/(tabs)/launch-checklist.tsx` — a new tab tracking every pre-submission requirement with progress saved to AsyncStorage.

### Features

1. **Checklist Items** (16 total):
   App Store Connect App Created, Bundle ID Verified, Export Compliance Set, Content Rights Confirmed, Age Rating Set, App Store Screenshots Captured, App Store Metadata Reviewed, EAS Build Completed, TestFlight Beta Testing Active, Privacy Policy URL Deployed, Play Console App Created, Play Store Screenshots Captured, Play Store Metadata Reviewed, Play Store Privacy Policy URL Set, Google Play App Signing Configured, Submission Button Clicked

2. **Progress Tracking**
   - Show X / 16 items complete with visual progress bar
   - AsyncStorage key: `@jobble/launch_checklist`

3. **Item Detail Cards**
   - Title, description, status (pending/done), tap to toggle
   - Done: green checkmark + faded. Pending: full opacity

4. **Launch Ready Badge**
   - All 16 checked = banner + Launch Commander badge
   - AsyncStorage key: `@jobble/launch_ready_badge`

5. **Quick Actions**
   - Reset Checklist (with confirmation alert)
   - Export Status (via Share API)

6. **Contextual Hints** per item explaining what done means

### Implementation Rules
- New tab: `app/(tabs)/launch-checklist.tsx`
- Follow existing tab patterns: Tab, ScrollView, Section cards
- Use existing theme context, language context, AsyncStorage patterns
- TSC must pass 0 errors after changes
- i18n: add keys to en.json + zh.json (use t() for all user-facing text)
- Register in `app/(tabs)/_layout.tsx`
- Icon: `rocket-launch` (MaterialCommunityIcons)
- Label: t('tabs.launchChecklist')
