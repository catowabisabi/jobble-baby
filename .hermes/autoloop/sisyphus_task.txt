## Task: Implement Asymmetric Growth Dashboard — Left/Right Body Part Comparison

Create a new tab for tracking and comparing left/right body part measurements to detect asymmetric growth patterns in infants.

## Requirements

### Tab Name
`asymmetric-growth` — add to `JobbleBaby/app/(tabs)/` and register in `_layout.tsx`

### Features
1. **Body Part Selector**
   - List of measurable body parts: head circumference, arm length, leg length, foot length, hand width
   - Each part has left/right measurement fields
   - Age-appropriate measurement guidance

2. **Asymmetry Index Calculator**
   - Calculate percentage difference between left and right
   - Formula: |L - R| / ((L + R) / 2) * 100
   - Display as: Normal (<5%), Mild (5-10%), Moderate (10-15%), Significant (>15%)
   - Color coding: green/yellow/orange/red

3. **Growth Trend Chart**
   - Line chart showing asymmetry percentage over time
   - Highlight when asymmetry increases or decreases
   - Correlation with developmental milestones

4. **Reference Ranges**
   - AAP normal asymmetry ranges by age
   - When to refer to specialist (pediatric orthopedist/neurologist)
   - Normal variants vs concerning patterns

5. **Measurement Logger**
   - Date, body part, left measurement, right measurement, notes
   - Photo attachment for visual reference (optional)
   - Reminder scheduling for regular checks

6. **Alert System**
   - Notify when asymmetry exceeds threshold
   - Recommend pediatrician referral if >10%
   - Link to 8-month storm tab if developmental factors suspected
