## Your Task
Implement a new tab: `app/(tabs)/clinician-portal.tsx`

### Features Required

1. **Clinician Hub Home**
   - "Prepare Visit Report" primary button
   - Date range selector: Last 30 days / 60 days / 90 days / Custom
   - Visit history list (past visits with date, doctor name, notes)
   - "Schedule Pre-Visit Checklist" card showing pending items for baby's age

2. **Visit Report Generator**
   - Toggle sections to include: growth chart, milestone timeline, feeding summary, sleep log, cry frequency, allergen log, assessment scores
   - Generate a structured summary as a scrollable preview screen
   - "Share via..." button → native iOS/Android share sheet (via expo-sharing)
   - "Save PDF" button → via expo-print
   - Sections collapsible for compact sharing

3. **Report Sections** (each collapsible):
   - **Growth**: WHO percentile chart (reuses existing growth.tsx data) + measurements table with dates
   - **Milestones**: completed milestones + any delayed ones with age-adjusted benchmarks
   - **Feeding**: average daily intake, method breakdown (BF/formula/mixed), any concerns
   - **Sleep**: total hours/day, night wakings, sleep efficiency, regression events
   - **Cry**: total minutes/day, pattern classification if cry-analyzer data available
   - **Allergen**: introduction timeline, reactions logged
   - **Assessments**: Hazelbaker score, jaw symmetry, reflex integration status (from tongue-tie.tsx and reflex-integration.tsx)

4. **Visit History**
   - Add past visit: date, doctor name, clinic, notes, action items
   - List view: date + doctor name, tap to expand notes
   - Edit/delete past visits

5. **Pre-Visit Checklist**
   - Automated checklist based on baby's age from profile:
     - "Vaccination due? Check vaccination schedule"
     - "Growth measurement recorded this month?"
     - "Any assessments pending (tongue tie, reflex)?"
   - Check off items, save state to AsyncStorage
