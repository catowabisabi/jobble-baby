# Pediatric Report PDF Export — Task for Sisyphus

## Goal
Implement **Pediatric Report PDF Export** tab — generate a shareable PDF summary of the baby's health data for pediatrician visits, including growth chart with WHO percentile bands, milestone timeline, feeding history, and sleep summary.

## Tech Stack
- Expo SDK (managed workflow) — NO react-native-pdf-lib or react-native-html-to-pdf (not compatible with Expo managed workflow)
- Use **expo-print** + **expo-sharing** for PDF generation and sharing
- Build HTML string → `await Print.printToFileAsync({ html })` → share via `Sharing.shareAsync()`

## Reference Files
- `app/(tabs)/growth.tsx` — for WHO growth data structure and chart data
- `app/(tabs)/milestones.tsx` — for milestone timeline
- `app/(tabs)/tracking.tsx` — for feeding/diaper/sleep log

## UI Layout
1. **Header**: "Pediatric Report" (en) / "兒科報告" (zh)
2. **Baby Info Card**: Name, birth date, current age (calculated from profile), gender
3. **Report Sections** (all in one scrollable view, one Print button at bottom):
   - Growth Chart: text table showing date, weight (kg), height (cm), head circumference, plotted against WHO percentile ranges. Not a chart image — a clean text table with percentile bands labeled.
   - Milestone Timeline: chronological list of key milestones with dates and ages
   - Feeding Summary: last 7 days of feeding entries aggregated (total feeds, total ml/breastfeeding duration)
   - Sleep Summary: last 7 days aggregated (total sleep hours, average longest stretch)
   - Allergen Status: quick list of introduced allergens and dates
4. **Print/Share Button**: "Export PDF" → `Print.printToFileAsync({ html })` → `Sharing.shareAsync(uri)`

## HTML Template for PDF
Build a clean HTML string with inline CSS. Style for A4 printing. Use @import url for fonts if needed, or system fonts. Structure:
```
<!DOCTYPE html>
<html><head><meta charset="utf-8"><style>
  body { font-family: -apple-system, sans-serif; padding: 20px; color: #333; }
  h1 { color: #1a1a2e; border-bottom: 2px solid #3B82F6; }
  h2 { color: #3B82F6; margin-top: 20px; }
  table { width: 100%; border-collapse: collapse; margin-top: 10px; }
  th, td { border: 1px solid #ddd; padding: 8px; text-align: left; }
  th { background: #f0f4ff; }
  .section { page-break-inside: avoid; }
</style></head><body>
<h1>${babyName} — Pediatric Health Report</h1>
<p>Generated: ${date} | Baby age: ${age}</p>
... sections ...
</body></html>
```
