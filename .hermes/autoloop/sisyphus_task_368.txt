## Task for Sisyphus

Create `JobbleBaby/app/(tabs)/autonomic-readiness.tsx` — a new tab that tracks the baby's autonomic nervous system maturation through behavioral proxies.

## UX OVERVIEW
Parents cannot measure vagal tone or cortisol directly. This tab uses OBSERVABLE BEHAVIORS as proxies:
- Stress response quality (crying recovery speed, startle response)
- Feeding stability (swallow-breathe coordination, feeding efficiency)
- Sleep autonomic markers (HRV-like patterns via wake-after-sleep-onset)
- Self-soothing capacity emergence

## STEP 1 — Create `autonomic-readiness.tsx`

Design: SafeAreaView + ScrollView, themed (COLORS, useLanguage, useTheme), single-column layout.

**SECTION A — Autonomic Readiness Score (Hero)**
- Composite 0-100 score displayed prominently
- Algorithm: weighted average of 4 sub-scores (see Section D)
- Color-coded: red <40, yellow 40-70, green >70
- Shows label: "Autonomic Readiness for [solid foods / sleep training / teething]"
- Based on baby's current age and observed behaviors

**SECTION B — Stress Response Tracker**
- Log stress events: startle, overstimulation, teething pain, vaccination
- Each entry: date, trigger type picker, intensity 1-5, recovery time (seconds), recovery quality picker (spontaneous/soothed/prolonged)
- Recovery Speed Score: average recovery time normalized to age-expected
- Startle Response Log: frequency per day, amplitude rating 1-5
- Weekly trend chart (simple line of recovery speed over time)

**SECTION C — Feeding Autonomic Stability**
- Log each feed with autonomic notes:
  - Swallow-breathe coordination rating 1-5 (5=perfectly coordinated)
  - Desaturation events (YN toggle + count if yes)
  - Feeding efficiency (good/slow/poor)
  - Post-feed autonomic state: calm/active/fussy/unsettled
- Running Swallow-Breathe Coordination Score
- Alerts: if coordination score drops below 3 for 3+ consecutive feeds

**SECTION D — Sleep Autonomic Quality**
- Track overnight:
  - Wake-after-sleep-onset (WASO) minutes
  - Number of autonomic arousals (spontaneous wakeups with autonomic signs)
  - Heart rate proxy: woke upset vs woke calm
- Autonomic Sleep Quality Score: based on WASO + arousal quality
- Link to existing sleep tracking data if possible

**SECTION E — Self-Soothing Emergence Timeline**
- Track emergence of self-soothing behaviors:
  - Hand-to-mouth/gentle thumb sucking (0-3mo)
  - Transitional objects (6-12mo)
  - Self-initiated sleep onset (12mo+)
- Each: behavior name, age first observed, frequency now
- Self-Soothing Index: 0-25 based on number + quality of behaviors

**SECTION F — Composite Readiness Algorithm**
```
Overall Score = (Stress_Recovery_Score × 0.25) 
              + (Feeding_Autonomic_Score × 0.30) 
              + (Sleep_Quality_Score × 0.25) 
              + (Self_Soothing_Index × 0.20)

Readiness for Solid Foods = if Overall > 50 AND Feeding_Autonomic_Score > 3.5
Readiness for Sleep Training = if Overall > 60 AND Sleep_Quality_Score > 3.0 AND age > 4mo
Readiness for Teething Stress = if Overall > 40
```

**SECTION G — Readiness Summary**
- 3 cards: Solid Foods Readiness, Sleep Training Readiness, Teething Stress Readiness
- Each: YES/NO/NOT_YET with explanation
- Recommendations per readiness area
