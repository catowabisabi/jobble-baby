# Task: Fix interoceptive.tsx hardcoded label strings → i18n

## Context
Painpoint #25: interoceptive.tsx has 26+ hardcoded English label strings in 4 arrays that are rendered as user-facing text in the UI. These need i18n treatment before App Store submission.

## Files to Modify
- `JobbleBaby/app/(tabs)/interoceptive.tsx`
- `JobbleBaby/app/i18n/en.json`
- `JobbleBaby/app/i18n/zh.json`

Scan the full file to find any additional hardcoded label arrays.

### Step 2 — Add i18n keys
For each hardcoded label, add a key to `en.json` and `zh.json` under `interoceptive` section.

Pattern: `interoceptive.label.{arrayName}.{value}`
e.g., `interoceptive.label.needOptions.feed`, `interoceptive.label.bodyRegions.head`, etc.

If a `zh.json` translation key is missing, use the English value as placeholder (copy English text).

### Step 3 — Update interoceptive.tsx
For each array, change from:
```
{ value: 'feed', label: 'Feed' }
```
To:
```
{ value: 'feed', label: t('interoceptive.label.needOptions.feed') }
```

Also update `accessibilityLabel={o.label}` to use the i18n key too:
```
accessibilityLabel={t('interoceptive.label.needOptions.feed')}
```

The `t()` function is available via `const { t } = useLanguage()` at the top of the component.
