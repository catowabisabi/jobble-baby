## Objective
Implement the Gut Resilience Index Navigator — a new tab that tracks the microbiome-gut-skin axis for infants.

## Background
Bifidobacterium dominance (70-90% of infant gut flora in first 6 months) is the keystone for immune education. When it declines (antibiotics, formula, C-section), gut barrier weakens, TEWL increases, atopic dermatitis risk rises. The app currently tracks allergens but not the underlying gut microbiome proxies.

## Task
Create app/(tabs)/gut-resilience-navigator.tsx

### Sections Required

**1. Stool Biome Proxy Logger**
- Log entries: date, frequency (times/day), consistency (5 options: watery/soft/normal/formed/hard), color (6 options: yellow/green/brown/black/white/red), smell (4 options: normal/sour/foul/其他), antibiotic_exposure (yes/no), feeding_type (breast/formula/mixed/solid)
- Store key: @jobble/stool_biome_proxy
- Show last 14 days as a scrollable card list

**2. Bifido Dominance Tracker**
- Input fields: breastfed_direct (times/day), breastfed_pumped (ml), formula_feeds (times/day), probiotic_drops (yes/no + frequency), delivery_mode (vaginal/C-section), antibiotics_last_14d (yes/no)
- Calculated "Bifido Support Score" (0-100):
  - +30 if exclusively breastfed
  - +20 if ≥4 breastfeeds/day
  - +15 if probiotic drops used
  - +15 if vaginal delivery
  - -25 if C-section
  - -20 if antibiotics in last 14 days
  - -10 per formula feed >2/day
  - Min 0, max 100
- Store key: @jobble/bifido_support_score
- Display score as a large circular gauge (color: green >60, yellow 30-60, red <30)

**3. Gut Barrier Integrity Index**
- TEWL proxy input: cheek skin condition (smooth/normal/dry/flaking), parent-reported "skin sensitivity" rating 1-5
- Color-coded gut permeability risk: green (low), yellow (medium), red (high)
- Formula: if cheek=flaking AND sensitivity≥4 → HIGH risk; if cheek=dry OR sensitivity≥3 → MEDIUM; else LOW
- Store key: @jobble/gut_barrier_index
- Show as color-coded card with explanatory text

**4. Secretory IgA Activity Log**
- Log entries: date, mucus_quality (thin-clear/thick-white/yellow/green), respiratory_infections_last_30d (count), diarrhea_episodes_last_30d (count), ear_infections_last_30d (count)
- Store key: @jobble/siga_activity_log
- Show latest entry + 30-day trend line for each metric

**5. Gut-Skin Axis Correlation Dashboard**
- Line chart (Recharts) showing 30-day trend:
  - Line 1: Stool quality score (watery=1, soft=2, normal=3, formed=4, hard=5)
  - Line 2: Rash/eczema frequency (incidents per week, from skin-thermal-regulation data if available, else manual entry)
  - Line 3: Bifido Support Score
- Color legend and annotations for correlation insights

**6. Atopic March Risk Alert**
- Triggers when ALL of: Bifido Support Score <40 + stool quality declining (trend) + gut permeability HIGH + rash frequency ≥2/week
- Alert card: red border, icon, message "Gut-Immune Consultation Recommended — Multiple risk factors for atopic march detected. Consider pediatrician consultation."
- Store key: @jobble/atopic_risk_flag
