# Task: Build Onboarding Wizard

## Context
Jobble Baby - AI job-hunting app. User uploads CV → AI analysis → subscribes.
Goal: 4-step onboarding wizard to accelerate Aha Moment from 3-5 days to under 5 minutes.

## 4 Steps
1. Upload CV → AI score reveal (the Aha Moment)
2. Job preferences → matching jobs preview
3. One interview question → instant AI feedback
4. Enable notifications → recruiter radar activates

## Your Tasks

### Frontend (src/app/onboarding.tsx)
- 4-step wizard with progress bar (1/4 → 4/4)
- Step 1: File picker → POST /api/v1/cv/upload → animated score reveal (1-10 + category breakdown)
- Step 2: Form (job_type, location, salary slider) → show "Found X jobs" preview cards
- Step 3: One HR question → text input → POST /api/v1/interviews/submit → AI feedback display
- Step 4: Push notification toggle + permission request → radar activation animation

### Gate (src/app/_layout.tsx)
- Check SecureStore for onboarding_complete
- If missing → redirect to /onboarding
- On completion → set onboarding_complete=true → redirect to home

### Backend (backend/app/routes/)
- POST /api/v1/onboarding/complete
- Body: { step: 1|2|3|4, preferences?: { job_type, location, salary_expectation } }
- Track completion + update user profile with job_preferences
