# Task: Implement Bottle Feeding Navigator tab (Todo #118)

## Overview
Create a new tab `bottle-feeding.tsx` to help parents track bottle feeding mechanics, nipple flow rates, paced feeding practice, and feeding efficiency. This complements the existing `bottle-refusal.tsx` and `feeding-readiness.tsx` tabs.

## Features to Implement

### 1. Nipple Level Tracker
- 6 levels: 0=preemie, 1=newborn, 2=3mo, 3=6mo, 4=variable, 5=toddler
- Log current level + start date + notes
- Alert prompts at 3mo and 6mo to reassess level
- Storage key: `@jobble/nipple_level` → `{ level: number, started_at: string, notes: string }`

### 2. Feeding Efficiency Log
- Log: date, duration_min, volume_ml, nipple_level, pace_score (1-5), notes
- Calculate intake rate (ml/min) displayed per entry
- Storage key: `@jobble/bottle_session` → array of session objects

### 3. Paced Bottle Feeding Guide
- Step-by-step technique display (5 steps)
- Practice session logger: date, duration_min, notes
- Track total practice sessions count
- Storage key: `@jobble/pace_practice` → array of practice objects

### 4. Flow Mismatch Signals
- Checklist: coughing, gulping, underfeeding, excessive gas, refusal, choking
- Each signal shows "Consider advancing" or "Consider slowing down" guidance
- Educational summary card

### 5. Summary Dashboard
- Current nipple level with age-appropriate recommendation
- Recent efficiency trend (last 7 sessions)
- Paced feeding streak (consecutive days practiced)
- Next milestone alert (next level recommendation)
