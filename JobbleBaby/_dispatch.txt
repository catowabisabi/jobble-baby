## TASK #393: Implement Neuroplasticity Peak Tracker Tab

**Keywords:** critical_window_closing · plasticity_peak · myelination_wave · synaptic_pruning_rate · gaba_switch_timing

### Objective
Create a new tab `neuroplasticity.tsx` tracking infant brain plasticity peaks correlated with myelination waves and synaptic pruning rates.

### File Location
`JobbleBaby/app/(tabs)/neuroplasticity.tsx`

### Features
1. **Plasticity Timeline** — Visual timeline 0-12 months showing active plasticity peaks for: language (0-12mo peak), vision (0-4mo critical), motor (2-9mo sensitive), sensory integration (0-3y), gut-brain axis (0-12mo). Overlay baby's current age position.
2. **Myelination Wave Tracker** — Log myelination milestone events (head control, trunk stability, language sounds). Correlate with plasticity windows.
3. **Synaptic Pruning Correlation** — Show expected pruning rate curve overlaid with developmental milestone achievements. Alert if milestones lag behind pruning progress.
4. **Window Status Cards** — Cards per domain showing: window name, open/closing/closed status, days remaining (if closing), stimulation activities suggestions.
5. **2-Week Closing Alert** — Alert banner when any window is within 2 weeks of closing with suggested activities.
6. **Integration Links** — Link to existing: critical-periods tab, milestone tab, sensory-integration tab.
