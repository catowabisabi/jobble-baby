# Play Store Asset Specifications — Jobble Baby

## Feature Graphic

**Dimensions:** 1024 × 500 px
**Format:** JPG (90% quality) or PNG
**Color Profile:** sRGB
**Background:** Dark (#1A1A2E)

### Layout (left → right)

| Zone | Content |
|------|---------|
| Left 60% | App icon (512×512, centered vertically, subtle drop shadow) |
| Right 40% | App name "Jobble Baby" (bold, white, 56sp) |
|          | Tagline "Your Baby, Your Journey, Your App" (white, 24sp) |
|          | Row of 3 small badge icons: 📊 Tracking · 📈 Growth · ⏰ Schedule |

**Fonts:** Use system font or Nunito (Google Fonts) for friendly feel.
**Export:** 100% quality, sRGB, JPG 90% or lossless PNG.
