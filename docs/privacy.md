# Privacy Policy — Jobble Baby

**Effective Date:** June 2026  
**App:** Jobble Baby  
**Bundle ID:** com.jobblebaby.app

## Data Collection

Jobble Baby collects the following data to provide our services:

- **Baby Profile Data:** Name, date of birth, gender, photo (optional)
- **Tracking Data:** Feeding logs, diaper changes, sleep records, growth measurements
- **Health Information:** Allergen records, doctor visit notes, milestone achievements
- **Device Information:** Device type, OS version, app version
- **Usage Analytics:** Tab navigation, feature usage frequency (anonymous, aggregated)

---

## Data Usage

We use collected data solely for:
- Providing and improving app functionality
- Sending optional reminders (scheduled alerts, milestone notifications)
- Generating growth charts and milestone reports
- Local storage on device (no mandatory cloud sync required)
