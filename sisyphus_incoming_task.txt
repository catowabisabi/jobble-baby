## Your Task
Implement BOTH of the following in the JobbleBaby/ project root:

### A. Sentry Crash Reporting
1. Install: npm install --save-dev @sentry/react-native (in JobbleBaby/)
2. Create docs/SENTRY_SETUP.md with:
   - Instructions for user to create Sentry account at sentry.io
   - Steps to create a new React Native project in Sentry dashboard
   - How to get the DSN
   - How to set SENTRY_DSN in app.json or .env (as EXPO_PUBLIC_SENTRY_DSN)
   - How to test crash reporting (throw test error, verify in Sentry dashboard)
3. Modify app.json: add "expo": { "plugins": [["@sentry/react-native", {"EXPO_PUBLIC_SENTRY_DSN": "YOUR_DSN_HERE"}]] } or similar placeholder
4. Add sentry init to app/_layout.tsx or a dedicated sentry.ts file:
   ```
   import * as Sentry from '@sentry/react-native';
   Sentry.init({ dsn: process.env.EXPO_PUBLIC_SENTRY_DSN });
   ```
5. Ensure TSC passes after changes
