## TASK: Implement Indoor Air Quality + Baby Respiratory Navigator Tab

**Keywords:** indoor_air_quality · voc_emission_testing · respiratory_event_tracker

### Objective
Create a new tab that tracks indoor air quality alongside baby respiratory events, correlating environmental factors with health/sleep disruption.

### Steps
1. Create new file: `app/(tabs)/indoor-air-navigator.tsx`
2. Implement the following sections:
   - **Indoor Air Log** — parent logs daily: air purifier usage (on/off), open window duration (minutes), candles/incense (yes/no), cleaning products used, cooking events
   - **Respiratory Event Tracker** — coughing episodes (count), wheezing (0-3 severity), nasal congestion score (0-5), reliever medication use (yes/no + type)
   - **Correlation Dashboard** — simple chart showing: air quality events vs. respiratory episodes vs. sleep disruption score
   - **Room-by-Room AQ Score** — nursery, living room, kitchen rated 1-5 by ventilation + pollutant sources
   - **Alert System** — when VOC spike (candle/cleaning) coincides with baby congestion trend → push notification flag

3. Add AsyncStorage keys in `store/storage-keys.ts`:
   - INDOOR_AIR_LOG = '@jobble/indoor_air_log'
   - RESPIRATORY_EVENTS = '@jobble/respiratory_events'

4. Register tab in `_layout.tsx` under BOTTOM_TABS:
   ```tsx
   { name: 'indoor-air-navigator', title: 'Air Quality', icon: 'leaf' }
   ```

5. Add i18n keys in `en.json` and `zh.json`:
   ```json
   "indoorAir": {
     "title": "Indoor Air Quality",
     "airLog": { "purifier": "Air Purifier", "windowDuration": "Window Duration (min)", ... },
     "respiratory": { "coughCount": "Coughing Episodes", "wheezeSeverity": "Wheeze Severity", ... },
     "correlation": { "title": "AQ vs Health Correlation", ... },
     "roomScore": { "nursery": "Nursery", "livingRoom": "Living Room", ... },
     "alert": { "vocSpike": "VOC Spike Detected", ... }
   }
   ```

6. Run TSC after implementation: `cd JobbleBaby && npx tsc --noEmit` — must pass 0 errors

7. Run pre-submission audit: `cd JobbleBaby && node scripts/pre-submission-audit.js` — must PASS
